# Experiment: 2026-07-10 S119

## Objective

Evaluate a publicly documented latency-adaptive single-request baseline as a complement to the short-host validation-fill family.

## Public Data Used

Official competition resources were used through the hosted competition environment. Raw files and local caches are not included in this repository.

## Configuration Summary

The submission used one message and one post per candidate, live retained-candidate validation, an eight-candidate latency probe, a 17 second fast-path threshold, a 42 second safety margin, and a 0.95 fill budget fraction.
