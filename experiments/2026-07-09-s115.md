# Experiment: 2026-07-09 S115

## Objective

Test a higher-risk short-host variant that asks for two sequential posts inside a single message and keeps only candidates that validate both posts.

## Public Data Used

Official competition resources were used through the hosted competition environment. Raw files and local caches are not included in this repository.

## Configuration Summary

The submission used short `.co` host labels, one message per candidate, two distinct post targets per candidate, a required two-post validation threshold, and a 45 second safety margin.

## Metrics

Public leaderboard score.

## Results

| Submission | Status | Public score |
| --- | --- | --- |
| s115 | Complete | 4.675 |

Official reference: `54482152`.

## Observations

The two-post variant underperformed sharply, so subsequent experiments return to one post per candidate.

## Known Limitations

The result reflects one public evaluation and may vary across reruns.
